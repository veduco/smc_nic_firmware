COMMENTS:

Option ROM for E610, E810, X772, X/XL/XXV710, X540, X552, X550 and all AOC using Intel LAN Controller.

***For FCOE please use PXE2527 (this is the last package that supports FCOE)***

UEFI:
- Use PXE.nsh to flash the PXE and EFI Option ROM boot.

Linux:
- Make sure login as root and run ./install in the Driver directory.
- Make sure all *.sh has executable permission.
- Use PXE.sh to flash the PXE and EFI Option ROM boot.


Usage: To flash PXE to LAN1 run "PXE 1".

The BootIMG.FLB file format has changed to allow using four part Device IDs when necessary to distinguish the correct NVM image for a device. All utilities and software are able to read older versions of BootIMG.FLB. However, you must update any utilities software you use to a more recent version to use the new BootIMG.FLB. Please upgrade to the following versions (or a more recent version):
* BootUtil, v. 1.3.5.xxx
* Intel(R) PROSet for Windows* Device Manager, v. 17.1.xxx
* SMASH, v2-2.0.0.58
The current version can be downloaded at Intel's Ethernet Products information website: https://www.intel.com/content/www/us/en/download-center/home.html
